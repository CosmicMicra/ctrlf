# CTRL+F

**Critical Threat Reading & Literature Forum**

*Read between the lines.*

CTRL+F is a weekly reading group for security research. We read papers on AI security, secure systems, and emerging threats, then discuss the methods, findings, assumptions, and open questions.

Papers covered in our weekly meetings are added to the website with short briefs and links to the original research.

## The weekly format

1. **The setup** — What problem does the paper address?
2. **The breakdown** — What are the methods, evidence, and findings?
3. **The challenge** — Which assumptions and limitations matter?
4. **The open question** — What should we test next?

## The reading room

- Searchable paper library with topic filters
- Briefs covering findings, significance, and limitations
- Questions for discussion
- Links to original papers

Current topics include AI agents and MCP, LLM attacks, and security classics.
